# Selkorin VPN — desktop-приложение для macOS

Чёрно-белое футуристичное приложение (с драконом) для управления вашим
**собственным** VPN на протоколах **WireGuard** и **Xray VLESS + Reality**.
Никаких сторонних сервисов и подписок — приложение работает напрямую с вашим
сервером по SSH, а ключи не покидают ваш Mac.

![Серверы](build/ui-servers.png)

## Что умеет (всё по-настоящему, без заглушек)

| Раздел | Функция |
|--------|---------|
| **Серверы** | Добавить VPS по SSH (ключ или пароль), проверить связь, **развернуть WireGuard в один клик** (заливает и запускает усиленную установку), управлять несколькими серверами. |
| **Устройства** | Список клиентов с живой статистикой (`wg show`): онлайн-индикатор, последний хендшейк, трафик. Добавление устройства генерирует ключи на сервере и показывает **QR-код** + `.conf`. Отзыв доступа в один клик. |
| **Этот Mac** | Подключить сам компьютер к VPN через `wg-quick` (с запросом пароля администратора), включать/выключать туннели. |
| **Reality** | Установить Xray VLESS+Reality (обход DPI-блокировок) с маскировкой под реальный сайт, получить `vless://`-ссылку и QR. |

Технологии: Electron, WireGuard (Curve25519 · ChaCha20-Poly1305), Xray Reality,
локальное хранилище (ключи только на устройстве).

## Сборка `.app` (выполняется на вашем Mac)

> **Почему на Mac, а не «уже готовый .app»?** Финальную упаковку и подпись
> macOS-приложения Apple разрешает только на macOS, а рантайм Electron
> подтягивается с GitHub при установке. В песочнице, где приложение
> собиралось, доступ к GitHub закрыт политикой — поэтому исходники, дизайн,
> иконка и рабочая логика готовы, а `.app` собирается одной командой у вас.

### Требования
- macOS (Apple Silicon или Intel)
- [Node.js 18+](https://nodejs.org)
- для подключения самого Mac к VPN: `brew install wireguard-tools`

### Одной командой
```bash
cd selkorin-vpn
bash build.sh
```
Скрипт установит зависимости, соберёт иконку и создаст два приложения:
```
dist/Selkorin VPN-darwin-arm64/Selkorin VPN.app   ← Apple Silicon (M1–M4)
dist/Selkorin VPN-darwin-x64/Selkorin VPN.app     ← Intel
```

### Вручную
```bash
npm install
npm run make-icon      # собрать icon.icns из PNG
npm run pack:mac-arm   # Apple Silicon
npm run pack:mac-x64   # Intel
```

### Первый запуск (сборка без Apple Developer ID)
Приложение не подписано, поэтому Gatekeeper сначала его не пустит. Разово:
```bash
xattr -cr "/Applications/Selkorin VPN.app"
```
После этого открывается обычным двойным кликом. (Если появится
[собственный сертификат разработчика Apple], можно добавить подпись — приложение
к этому готово.)

## Как пользоваться

1. **Серверы → Добавить сервер.** Укажите IP/хост VPS, пользователя (`root`),
   SSH-ключ (рекомендуется) или пароль. Нажмите **Проверить**.
2. **Развернуть VPN.** На чистом Ubuntu/Debian-сервере кнопка сама поставит
   усиленный WireGuard, приватный DNS, файрвол и хардненинг (1–3 минуты, лог
   виден внизу). Если сервер уже настроен скриптами Selkorin — шаг можно
   пропустить.
3. **Устройства → Добавить устройство.** Введите имя (`phone`, `laptop`).
   Появится QR — отсканируйте приложением **WireGuard** на телефоне, либо
   сохраните `.conf`, либо сразу **подключите этот Mac**.
4. **Этот Mac.** Нажмите **Подключить** — приложение поднимет туннель
   (потребуется пароль администратора один раз).
5. **Reality** (по желанию). Если провайдер режет WireGuard — установите
   Reality и импортируйте `vless://`-ссылку в v2rayNG / Hiddify / Streisand.

## Структура проекта
```
selkorin-vpn/
├── build.sh                 # сборка .app на macOS
├── package.json
├── build/
│   ├── icon.icns            # иконка приложения (дракон)
│   ├── icons/               # PNG-исходники иконки
│   └── pack-icns.js         # сборка .icns (чистый Node)
├── resources/scripts/       # серверные скрипты (заливаются на VPS)
│   ├── install-server.sh
│   ├── add-client.sh
│   ├── del-client.sh
│   └── install-xray-reality.sh
└── src/
    ├── main/                # процесс Electron (SSH, wg-quick, IPC, хранилище)
    │   ├── main.js  preload.js  ssh.js  serverOps.js  wg.js  store.js
    └── renderer/            # интерфейс
        ├── index.html  styles.css  app.js  dragon.svg
```

## Безопасность
- Ключи и настройки хранятся только на этом Mac (`~/Library/Application Support/Selkorin VPN/`), файл с правами `0600`.
- Приватные ключи клиентов создаются на сервере; отдельный preshared-ключ на каждое устройство.
- Приложение не отправляет данные никуда, кроме вашего собственного сервера по SSH.
