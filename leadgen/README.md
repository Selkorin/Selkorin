# 🎯 Selkorin Lead Engine

Веб-приложение для **лидогенерации, парсинга и рассылок**. Опишите обычными
словами, кого вы ищете («Найди мне клиентов, кому нужен сайт»), — движок строит
план поиска и собирает свежие заявки из **Telegram-чатов**, **поиска Яндекса** и
**Яндекс.Карт** (бизнесы без сайта), оценивает каждый лид и предлагает первое
сообщение. Плюс отдельный модуль **Telegram-рассылок**: массовые сообщения,
реакции, лайки, кружки (видеосообщения) и накрутка просмотров.

> ⚠️ **Дисклеймер.** Автоматизация пользовательских аккаунтов Telegram и
> массовые действия нарушают правила Telegram и могут привести к блокировке
> номера. Скрейпинг чужих данных регулируется законом (152-ФЗ, GDPR и т.п.).
> Инструмент даётся «как есть» — ответственность за использование на вас.
> Начинайте с малых объёмов, соблюдайте паузы, пишите только по делу.

## Что умеет

| Модуль | Описание |
|---|---|
| 🔍 **Поиск лидов** | Запрос на естественном языке → план поиска → сбор кандидатов из 3 источников → AI-скоринг (0–100, hot/warm/cold) → инбокс лидов |
| 🗺️ **Яндекс.Карты** | Находит организации **без сайта** по категории и городу — готовые клиенты «на сайт» |
| 🔎 **Яндекс-поиск** | Свежие публичные заявки «нужен сайт / ищу разработчика» (официальный Yandex Search API) |
| ✈️ **Telegram-парсинг** | Читает указанные чаты через Telethon-сессию, вылавливает сообщения с признаками заявки |
| 📡 **Мониторы** | Сохранённые запросы, которые ищут лидов автоматически по расписанию |
| ✍️ **AI-сообщения** | Персональное первое сообщение и фоллоу-ап под каждый лид |
| 📣 **Рассылки** | Массовые сообщения (с персонализацией и spintax), реакции, лайки ❤️, кружки, просмотры — с человекоподобными паузами и суточными лимитами |
| 🧠 **Мозг (промты)** | Три системных промта видно и можно править прямо в интерфейсе / в `app/prompts.py` |

## Быстрый старт

```bash
cd leadgen
./run.sh                      # создаст venv, поставит зависимости, поднимет сервер
# открыть http://localhost:8000
```

Или вручную:

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Приложение стартует в **demo-режиме**: всё наполнено демо-данными и работает без
единого ключа. Скоринг в этом режиме — на встроенной эвристике.

## Переход в боевой режим (LIVE)

Откройте раздел **Настройки** в интерфейсе (или заполните `.env`) и добавьте:

1. **Claude API** (`ANTHROPIC_API_KEY`) — умный скоринг лидов и генерация писем. → console.anthropic.com
2. **Telegram** — на `my.telegram.org` получите `api_id` / `api_hash`, добавьте
   аккаунт во вкладке **Аккаунты** и войдите (код + при необходимости пароль 2FA).
   Сессия сохраняется — это и есть «телеграм-сессия» для парсинга и рассылок.
3. **Яндекс** (опционально) — `YANDEX_SEARCH_API_KEY` (формат `user:key`) и
   `YANDEX_MAPS_API_KEY` (Geosearch/Places API).
4. Переключите режим на **LIVE**.

## Архитектура

```
leadgen/
├── app/
│   ├── main.py            FastAPI: роутеры, статика, планировщик
│   ├── config.py          настройки из окружения
│   ├── db.py              SQLite (stdlib, без ORM)
│   ├── prompts.py         🧠 три промта движка
│   ├── ai.py              Claude + эвристический фолбэк
│   ├── sources/           yandex_maps · yandex_search · telegram_chats
│   ├── telegram/          client (сессии) · actions · safety (лимиты)
│   ├── services/          leadgen (оркестратор) · monitoring · outreach
│   └── routers/           REST API
└── web/                   index.html · styles.css · app.js  (SPA без сборки)
```

- **Backend** — Python + FastAPI, весь Telethon-код исполняется в одном фоновом
  event-loop, что исключает конфликты циклов.
- **Frontend** — чистый SPA на ванильном JS, раздаётся тем же сервером. Сборка
  не нужна.
- **Хранилище** — SQLite. Сессии Telegram и медиа — в `data/` (в git не попадают).

## Безопасность аккаунта

Все массовые действия проходят через `app/telegram/safety.py`:
- случайные паузы 8–22 сек между действиями (настраивается);
- суточные лимиты на сообщения и реакции;
- spintax и AI-персонализация, чтобы рассылка не была шаблонной.

Это снижает риск бана, но не отменяет его. Используйте с умом.
