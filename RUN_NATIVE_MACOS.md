# 🍎 Remote Support - Полнотекстовая инструкция для macOS

## Что это?

Это **нативное приложение для macOS** (как обычная программа в App Store), а не веб-страница.

После запуска вы получите:
- ✅ Приложение в Dock (панель с иконками внизу экрана)
- ✅ Собственное окно (не браузер)
- ✅ Интегрированный сервер (работает в фоне)
- ✅ Полностью локальное (без облака)

---

## 🚀 Как запустить (30 секунд)

### Шаг 1: Откройте Терминал

```bash
open -a Terminal
```

Или используйте `Cmd+Space` и напечатайте "Terminal"

### Шаг 2: Перейдите в проект

```bash
cd /path/to/Selkorin
```

Если не знаете путь, просто перетащите папку проекта в Терминал

### Шаг 3: Запустите

```bash
./RUN_MACOS_APP.sh
```

### Шаг 4: Ждите

Приложение будет:
1. Проверять зависимости (5 сек)
2. Устанавливать пакеты (30 сек)
3. Компилировать код (20 сек)
4. **Запускаться** ✅

---

## 📱 Использование приложения

Когда приложение запустится:

### На компьютере (Mac)

1. **Кликните** "Создать QR" (верхняя правая кнопка)
2. **Видите** большой QR-код на экране
3. **Поделитесь** инструкциями с пользователем телефона

### На телефоне (iOS/Android)

1. **Откройте** приложение "Камера"
2. **Наведите** на QR-код
3. **Нажмите** на уведомление
4. **Нажмите** кнопку "Разрешить подключение"
5. **Видите** баннер "Сессия активна"

### На компьютере (продолжение)

1. **Видите** телефон в списке устройств
2. **Кликните** на устройство
3. **Кликните** "Запустить экран телефона"
4. **Телефон** покажет запрос - нажмите "Разрешить"
5. **Видите** экран телефона на компьютере!

- **macOS** (любая версия)
- **Node.js 20.x**
  - Проверьте: `node --version`
  - Если нет: `brew install node@20`

## 🛑 Если что-то не работает

### Ошибка "command not found"

```bash
# Убедитесь что находитесь в папке проекта
pwd

# Должно быть что-то вроде:
# /path/to/Selkorin

# Если другое - перейдите туда
cd /path/to/Selkorin
```

### Ошибка "Port 3000 already in use"

```bash
# Просто запустите скрипт заново
./RUN_MACOS_APP.sh

# Или убейте процесс
lsof -ti:3000 | xargs kill -9
```

### "Node not found"

```bash
# Установите Node.js
brew install node@20

# Проверьте
node --version
```

### Остальные ошибки

```bash
# Полностью переустановите
rm -rf node_modules
npm install --legacy-peer-deps
./RUN_MACOS_APP.sh
```
