# ЕГЭ Тренажёр 2026 — Android-приложение

Офлайн-приложение для подготовки к ЕГЭ: тесты с вариантами ответов, карточки
и **мнемонические подсказки-запоминалки**. Контент учитывает изменения ФИПИ
на 2026 год.

## Что внутри

- **6 предметов:** Русский язык, Математика, Обществознание, История,
  Информатика, Биология.
- **120 тестовых вопросов** (по 20 на предмет; 4 варианта, разбор + мнемоника
  к каждому).
- **60 карточек** (по 10 на предмет; вопрос → ответ + мнемоника, переворот по
  нажатию).
- **Режимы:** тест по предмету, случайный смешанный тест (20 вопросов),
  карточки по предмету.
- **Изменения ЕГЭ-2026** встроены в задания: порог 150 слов в сочинении по
  русскому, смягчённый критерий К6, «только первый аргумент/тезис» в
  обществознании и истории, ограничение форматов файлов в информатике.
- Полностью **офлайн**, без интернет-разрешений и сбора данных.

## Установка APK

Готовый файл: `dist/ege-trenazher-2026.apk`.

1. Скопируйте APK на Android-телефон.
2. Разрешите установку из неизвестных источников (Настройки → Безопасность).
3. Откройте файл и установите.

Требования: Android 5.0 (API 21) и выше.

## Пересборка из исходников

Сборка сделана **без Gradle** — только инструментами командной строки
(так проще в ограниченном окружении). Нужны пакеты Ubuntu:
`aapt`, `dalvik-exchange`, `zipalign`, `apksigner`, `android-sdk-platform-23`
и JDK.

```bash
sudo apt-get install -y aapt apksigner zipalign dalvik-exchange android-sdk-platform-23
cd android-ege
./build.sh
# результат: dist/ege-trenazher-2026.apk
```

Цепочка сборки: `aapt` (ресурсы + R.java) → `javac` (target 8) →
`dalvik-exchange`/dx (dex) → `zipalign` → `apksigner`.

> Примечание: код написан в стиле Java 8 без лямбд, потому что классический
> дексер `dx` не поддерживает `invokedynamic`.

## Как пополнять контент

Все задания лежат в `Bank.java` в статическом блоке:

```java
q(ПРЕДМЕТ, "Текст вопроса",
  o("вариант 1", "вариант 2", "вариант 3", "вариант 4"), /*индекс верного*/ 0,
  "Разбор", "Мнемоника-запоминалка");

c(ПРЕДМЕТ, "Лицевая сторона", "Ответ", "Мнемоника");
```

Варианты ответов приложение **перемешивает** на лету, поэтому правильный
можно ставить на любую позицию.
