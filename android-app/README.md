# Selkorin — пользовательский клиент (Android)

Нативное Android-приложение для **конечных пользователей** вашего VPN — тот
же дракон, тот же чёрно-белый стиль, что и в клиенте для macOS. Пользователь
вставляет ключ, который выдал администратор (панель в `desktop-app/`), и
подключается одной кнопкой.

## Что умеет

| Функция | Описание |
|---------|----------|
| **WireGuard** | Полноценный туннель через официальную библиотеку `com.wireguard.android:tunnel` (та же, что использует официальное приложение WireGuard) — реальный VPN, не заглушка. |
| **VLESS / Reality** | Ключ можно сохранить и посмотреть/скопировать уже сейчас; подключение появится в одном из следующих обновлений (честно показано в интерфейсе, без фальшивой кнопки). |
| **Пароль** | Вход в приложение защищён паролем (PBKDF2 + AES-256-GCM, 210 000 итераций). Ключи не читаются без разблокировки. |
| **Биометрия** | Отпечаток / лицо через `BiometricPrompt`, привязано к ключу в Android Keystore (`setUserAuthenticationRequired`). |
| **Маскировка** | Переключатель меняет значок и название приложения на «Заметки» (через `activity-alias`) — не для обмана системы, а чтобы не привлекать внимание в списке приложений. Возврат — тем же переключателем. |

## Сборка APK

Собирается автоматически в GitHub Actions
(`.github/workflows/selkorin-android.yml`) при пуше в ветку: устанавливается
Android SDK, генерируются иконки из SVG, собирается debug-APK (подписан
автогенерируемым debug-ключом Gradle — этого достаточно для установки на
телефон вне Google Play) и публикуется в Releases.

## Установка

1. Скачай `Selkorin-Android.apk` из [Releases](../../releases).
2. Открой файл на телефоне (через браузер или файловый менеджер).
3. Android спросит разрешение «Установить из этого источника» — разреши для
   этого файла/приложения.
4. Установи и открой — приложение попросит задать пароль при первом запуске.

## Структура

```
android-app/
├── build/                       # SVG-иконки (растеризуются в CI)
├── app/
│   ├── build.gradle
│   └── src/main/
│       ├── AndroidManifest.xml
│       ├── java/com/selkorin/client/
│       │   ├── MainActivity.kt      # экран блокировки + основной экран
│       │   ├── Vault.kt             # зашифрованное хранилище ключей
│       │   ├── VpnManager.kt        # обёртка над WireGuard GoBackend
│       │   ├── BiometricHelper.kt   # Touch ID / Face unlock
│       │   └── KeyAdapter.kt        # список ключей (RecyclerView)
│       └── res/                     # layout, drawable, values
├── build.gradle
└── settings.gradle
```

## Безопасность
- Ключи хранятся в `SharedPreferences` приложения (песочница Android),
  зашифрованы AES-256-GCM ключом, выведенным из пароля (PBKDF2-HMAC-SHA256).
- Пароль для биометрии шифруется отдельным ключом в Android Keystore,
  привязанным к биометрическому датчику устройства.
- `android:allowBackup="false"` — зашифрованное хранилище не попадает в
  резервные копии.
