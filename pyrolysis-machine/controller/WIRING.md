# Электрическая схема контроллера (ESP32)

## Принцип fail-safe

Силовая цепь нагревателей построена так, что **любой отказ выключает
нагрев**:

```
~230В ──► автомат 16А ──► кнопка СТОП (NC, грибок) ──► контакты контактора ──► SSR ──► ТЭН 2×1,5 кВт
                                                          ▲                     ▲
                                       катушка ◄── реле-модуль ◄── GPIO26   GPIO25 (ШИМ окна PID)
```

- Катушка контактора держится только пока ESP32 активно выдаёт HIGH на
  GPIO26. Завис контроллер, пропало питание логики, сработала
  блокировка — контактор отпал, ТЭН обесточен.
- Кнопка аварийного останова — нормально замкнутая, стоит **в цепи
  катушки**, работает мимо контроллера.
- SSR управляет мощностью (медленный ШИМ от PID), контактор —
  разрешением. Двойное отключение: залипший SSR не страшен, пока есть
  контактор.

## Карта подключений ESP32 DevKit v1

| GPIO | Направление | Подключено | Примечание |
|---|---|---|---|
| 18 | out | SCK → MAX31855 ×2 | SPI общий |
| 19 | in | MISO ← MAX31855 ×2 | |
| 5 | out | CS модуля TC1 (реактор) | |
| 17 | out | CS модуля TC2 (пары) | |
| 34 | in (ADC) | датчик давления 0,5–4,5 В | через делитель 18,7к/10к (макс 2,45 В на пине) |
| 35 | in (ADC) | MQ-2 аналоговый выход | через делитель 2:1; прогрев датчика 24 ч |
| 25 | out | вход SSR-40DA (3–32 В DC) | |
| 26 | out | IN реле-модуля 5 В (катушка контактора) | реле-модуль с оптопарой, active-HIGH |
| 27 | out | зуммер 3,3 В активный | |

платы. Земли объединить в одной точке.

## Термопары

- Тип K в стальной гильзе; кабель — компенсационный, не медный
  (медь до клеммника внесёт ошибку в десятки градусов).
- TC1 — в гильзу до середины реактора. TC2 — в паровой стояк.
- Модули MAX31855 — в боксе, подальше от силовых проводов.

## Датчик давления

Ставить **только в холодной зоне**: на тройник линии продувки через
импульсную трубку 300–500 мм (газ в тупиковой трубке остывает).
Прямо в горячий реактор автомобильный датчик встанет и умрёт, а перед
смертью соврёт.

## Калибровка MQ-2

1. Прогреть датчик 24 ч.
2. Записать показания чистого воздуха (обычно raw 400–900).
3. Поднести незажжённую газовую зажигалку с 30 см — записать пик.
4. Порог `GAS_TRIP_RAW` в прошивке выставить между этими значениями
   ближе к чистому воздуху (например, воздух+50 %).

## Прошивка

`pyrolysis_controller.ino` — Arduino IDE, плата "ESP32 Dev Module",
библиотека Adafruit MAX31855. Логика: старт кнопкой → 60 с на отход →
рампа 5 °C/мин до 430 °C → выдержка → остывание. Все блокировки — в
`checkInterlocks()`; выход из аварии только перезапуском питания после
осмотра установки.

Телеметрия идёт в Serial (115200) в CSV. Для журнала прогона:

```bash
# Linux; COM-порт под Windows — через PuTTY logging
cat /dev/ttyUSB0 > run_$(date +%Y%m%d_%H%M).csv
```

Анализ журнала с помощью ИИ — [../ai/analyze_run.py](../ai/analyze_run.py).
