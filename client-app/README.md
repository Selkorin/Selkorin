# Selkorin — пользовательский клиент (macOS)

Лёгкое приложение для **конечных пользователей** вашего VPN. Пользователь
вставляет ключ, который выдал администратор (из админ-панели Selkorin), и
подключается одной кнопкой. Всё чёрно-белое, с драконом — в едином стиле.

> Админ-панель (управление сервером, генератор ключей, статистика) — это
> отдельное приложение в `desktop-app/`. Здесь — **клиент** для раздачи людям.

## Что умеет

| Функция | Описание |
|---------|----------|
| **Вставить ключ** | Поддерживает `vless://…` (Reality) и WireGuard-конфиг `[Interface]`. Ключ сохраняется **зашифрованным** (AES-256-GCM) на устройстве. |
| **Подключение** | Большая кнопка вкл/выкл. VLESS/Reality поднимается встроенным **Xray-core** (локальный SOCKS + системный прокси), WireGuard — через `wg-quick`. |
| **Пароль / PIN** | Вход в приложение защищён паролем. Ключи расшифровываются только после ввода. |
| **Touch ID** | Разблокировка отпечатком/лицом (пароль хранится в Keychain через safeStorage). |
| **Скрытие приложения** | Убрать из Dock и переключателя приложений. Вернуть окно — `⌘ + ⌥ + S`. |
| **Автоблокировка** | Автоматически блокировать приложение при бездействии. |

## Сборка `.app`

Сборка идёт автоматически в GitHub Actions
(`.github/workflows/selkorin-client-mac.yml`) при пуше в ветку: собираются
`.dmg` для Apple Silicon и Intel, встраивается Xray-core, публикуется в Releases.

Локально на Mac:
```bash
cd client-app
bash build.sh
```
Требуется macOS + Node.js 18+. Для WireGuard-туннеля пользователю нужен
`brew install wireguard-tools` (VLESS/Reality работает без него — движок встроен).

## Первый запуск (без Apple Developer ID)
```bash
xattr -cr "/Applications/Selkorin.app"
```

## Безопасность
- Ключи и пароль-верификатор лежат в `~/Library/Application Support/Selkorin/selkorin-client.json` (права `0600`); секреты зашифрованы ключом из мастер-пароля (scrypt N=32768).
- Приложение не отправляет данные никуда, кроме вашего VPN-сервера.
- Touch ID использует системный Keychain (safeStorage), пароль в открытом виде не хранится.
