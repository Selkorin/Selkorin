# 🍎 Remote Support - Native macOS Application

Полное приложение для macOS, которое работает как обычное приложение в Dock (не веб-страница).

## ⚡ Быстрый старт (2 минуты)

### 1️⃣ Первая настройка

```bash
# Перейдите в директорию проекта
cd /path/to/Selkorin

# Первый запуск
./RUN_MACOS_APP.sh
```

### 2️⃣ Готово! 🎉

Приложение откроется как обычное macOS приложение с:
- ✅ Собственным окном
- ✅ Иконкой в Dock
- ✅ Интегрированным бэкенд сервером
- ✅ Полностью локальным хранилищем

## 📱 Как использовать

### На компьютере (в приложении)

1. **Создать соединение**
   - Кликните на кнопку "Создать QR"
   - Появится QR-код

2. **Подключить телефон**
   - На телефоне откройте камеру
   - Отсканируйте QR-код
   - Подтвердите подключение

3. **Управлять устройством**
   - В списке видите подключенные устройства
   - Кликните на устройство
   - Нажмите "Запустить экран телефона"
   - Телефон должен подтвердить

### На телефоне

1. Видите экран с большой кнопкой "Разрешить подключение"
2. После подтверждения видите баннер "Сессия активна"
3. Кнопка "Отключиться" всегда видна
4. Оператор может запросить экран/камеру

## 🐛 Решение проблем

### Ошибка "Port 3000 already in use"

```bash
# Убейте процесс
lsof -ti:3000 | xargs kill -9

# Запустите снова
./RUN_MACOS_APP.sh
```

### Ошибка "Cannot find module"

```bash
# Переустановите зависимости
rm -rf node_modules
npm install --legacy-peer-deps
./RUN_MACOS_APP.sh
```

### Приложение не запускается

```bash
# Запустите с логами
npm run electron:dev

# Проверьте консоль на ошибки
```

### Белый экран в приложении

```bash
# Очистите кэш и перезагрузитесь
rm -rf electron/dist apps/server/dev.db
./RUN_MACOS_APP.sh
```

### "Cannot read property 'app' of undefined"

```bash
# Убедитесь что Node.js установлен правильно
node --version
npm --version

# Переустановите Electron
npm install electron --save-dev --force
```

## 🔧 Конфигурация

### Переменные окружения

Находятся в `apps/server/.env`:

```env
NODE_ENV=development
PORT=3000
DATABASE_URL=file:./dev.db
```

### Иконка приложения

Находится в `electron/assets/`:
- `icon.svg` - исходный векторный файл
- `icon.png` - для сборки

Чтобы изменить иконку:
1. Отредактируйте `icon.svg`
2. Пересоздайте `icon.png`
3. Заново соберите: `npm run electron:build`
