Heads up about "screen off": mobile browsers pause camera capture when the screen fully locks, so a browser can keep streaming with the screen dimmed / wake-lock held, but not fully powered off. For true screen-off background streaming you need a native app with a foreground camera service (allowed on Android; iOS restricts background camera).
