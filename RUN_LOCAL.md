# 💻 Локальный запуск WAI (работа из браузера, без сервера)

Поднимает бэкенд **и** интерфейс на одном адресе **http://localhost:3000**.
Страница «Лиды» (Яндекс / 2ГИС / ВК / Telegram) и весь дашборд работают локально.

## Что нужно один раз
- **Node.js 20 LTS** — скачать с https://nodejs.org (просто установить).

## Запуск на Mac (самый простой способ)
1. Дважды кликни по файлу **`WAI-Local.command`** в Finder.
   - Если macOS напишет «не удаётся открыть, неизвестный разработчик» —
     кликни по файлу **правой кнопкой → «Открыть» → «Открыть»** (только в первый раз).
2. Откроется Терминал: скрипт сам поставит зависимости, соберёт интерфейс
   и запустит сервер. Через несколько секунд браузер откроется на
   **http://localhost:3000**.
3. Чтобы остановить — закрой окно Терминала или нажми `Ctrl + C`.

## Запуск из терминала (Mac/Linux)
```bash
./start-local.sh
```

## Ключи API
При первом запуске создаётся файл **`.env`** (копия `.env.development`).
Открой его и впиши ключи там, где нужно:
```env
YANDEX_MAPS_API_KEY=...   # для парсера Яндекс.Карт
TWOGIS_API_KEY=...        # 2ГИС (по желанию)
VK_SERVICE_TOKEN=...      # ВКонтакте (по желанию)
TGSTAT_API_KEY=...        # поиск Telegram-каналов по нише (по желанию)
```
Где взять ключи — см. **LEADGEN.md**. Без ключа интерфейс открывается,
но поиск по этому источнику вернёт понятную ошибку «ключ не задан».

## Данные
Лиды хранятся локально в SQLite-файле `data/wai.db` (создаётся автоматически,
в git не попадает). Экспорт в CSV — кнопкой на странице «Лиды».

## Если что-то не запускается
- `node -v` должен показать `v20.x` (или 18+).
- Удали папки `node_modules` и `web/node_modules` и запусти скрипт заново.
- Порт 3000 занят? Поменяй `PORT` в `.env`.
