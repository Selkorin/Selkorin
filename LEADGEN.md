# 🎯 Лид-генерация через Яндекс.Карты (Yandex Places API)

Модуль собирает компании с Яндекс.Карт по нише и региону, складывает их в таблицу
(БД + страница в дашборде) и позволяет выгрузить в CSV. Можно отбирать компании
**у которых нет сайта** — это горячие лиды на разработку сайта / маркетинг.

> Реализовано через **официальный Yandex Places API (Geosearch)**, а не через
> «парсинг страниц». Это легально, стабильно и не ломается от капчи/блокировок.

---

## 1. Как получить API-ключ (бесплатно)

1. Зайдите в кабинет разработчика Яндекса: **https://developer.tech.yandex.ru/**
2. Войдите под своим Яндекс-аккаунтом.
3. Нажмите **«Подключить API»** → выберите сервис **«Geosearch / Поиск по организациям»**
   (в интерфейсе может называться *«Places API»* или *«JavaScript API и HTTP Геокодер»* —
   нужен именно **HTTP-ключ для поиска по организациям**).
4. Заполните короткую анкету (название проекта — например «WAI лид-ген»).
5. Скопируйте выданный ключ (выглядит как длинная строка с дефисами).

Бесплатный лимит — порядка **500 запросов в сутки** (хватает на регулярный сбор).
Для больших объёмов есть платные тарифы.

---

## 2. Настройка

Добавьте ключ в `.env`:

```env
YANDEX_MAPS_API_KEY=ваш-ключ-сюда
```

Перезапустите бэкенд:

```bash
npm run dev
```

---

## 3. Использование через интерфейс

1. Откройте дашборд → в меню слева пункт **«Лиды»**.
2. Введите **нишу** (например `кофейня`, `стоматология`, `автосервис`) и **город**.
3. При желании включите галочку **«Только без сайта»**.
4. Нажмите **«Собрать компании»** — результаты появятся в таблице и сохранятся в БД.
5. Управляйте статусами лидов (Новый → Связались → Клиент) прямо в таблице.
6. Кнопка **«Экспорт CSV»** выгружает таблицу (открывается в Excel / Google Таблицах).

## 4. Использование через API

### Собрать компании
```bash
curl -X POST http://localhost:3000/api/leads/search \
  -H "Content-Type: application/json" \
  -d '{
    "niche": "кофейня",
    "region": "Москва",
    "noWebsiteOnly": true,
    "limit": 200,
    "save": true
  }'
```

Ответ:
```json
{ "success": true, "found": 47, "saved": 47, "leads": [ ... ] }
```

### Список лидов (с фильтрами)
```bash
# Только без сайта
GET /api/leads?hasWebsite=false

# По нише и статусу
GET /api/leads?niche=кофейня&status=new&page=1&limit=50
```

### Статистика
```bash
GET /api/leads/stats
```

### Обновить статус / заметку
```bash
PUT /api/leads/:id
{ "status": "contacted", "notes": "Отправили КП" }
```

### Экспорт в CSV
```bash
GET /api/leads/export/csv?hasWebsite=false
```

## 5. Какие поля собираются

| Поле        | Описание                                  |
|-------------|-------------------------------------------|
| name        | Название компании                         |
| category    | Основная рубрика                          |
| categories  | Все рубрики                               |
| address     | Адрес                                     |
| phone       | Телефон(ы)                                |
| website     | Сайт (пусто = «нет сайта»)                |
| hasWebsite  | Флаг наличия сайта                        |
| latitude/longitude | Координаты                         |
| yandexUrl   | Ссылка на карточку в Яндекс.Картах        |
| hours       | Часы работы                               |
| niche/region| По какому запросу найден                  |
| status      | Статус в воронке (new/contacted/...)      |

---

## 6. Ограничения и заметки

- Яндекс отдаёт максимум **500 организаций на один поисковый запрос**. Чтобы собрать
  больше по большому городу — дробите по районам (через параметры `ll` + `spn`,
  они поддерживаются в `POST /api/leads/search`).
- Дубликаты (по названию+адресу) автоматически отсеиваются при сохранении.
- Параметр `noWebsiteOnly` фильтрует компании по отсутствию поля «сайт» в ответе API.
