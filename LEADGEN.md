# 🎯 Лид-генерация через Яндекс.Карты (Yandex Places API)

Модуль собирает компании с Яндекс.Карт по нише и региону, складывает их в таблицу
(БД + страница в дашборде) и позволяет выгрузить в CSV. Можно отбирать компании
**у которых нет сайта** — это горячие лиды на разработку сайта / маркетинг.

> Реализовано через **официальный Yandex Places API (Geosearch)**, а не через
> «парсинг страниц». Это легально, стабильно и не ломается от капчи/блокировок.

---

## 1. Как получить API-ключ (бесплатно)

1. Зайдите в кабинет разработчика Яндекса: **https://developer.tech.yandex.ru/**
2. Войдите под своим Яндекс-аккаунтом.
3. Нажмите **«Подключить API»** → выберите сервис **«Geosearch / Поиск по организациям»**
   (в интерфейсе может называться *«Places API»* или *«JavaScript API и HTTP Геокодер»* —
   нужен именно **HTTP-ключ для поиска по организациям**).
4. Заполните короткую анкету (название проекта — например «WAI лид-ген»).
5. Скопируйте выданный ключ (выглядит как длинная строка с дефисами).

Бесплатный лимит — порядка **500 запросов в сутки** (хватает на регулярный сбор).
Для больших объёмов есть платные тарифы.

### Источник 2ГИС — официальный Catalog/Places API

1. Зайдите в кабинет: **https://dev.2gis.com/**
2. Создайте проект и подключите продукт **«Places API / Catalog API»**.
3. Скопируйте ключ.

### Источник 2ГИС — браузерный скрапер (parser-2gis, без ключа)

Альтернатива API — внешний OSS-инструмент
[parser-2gis](https://github.com/interlark/parser-2gis). Он гоняет Chrome по
сайту 2gis.ru и собирает публичные карточки. **Ключ не нужен.**

```bash
pipx install parser-2gis   # или: pip install parser-2gis
# + установленный Google Chrome / Chromium
```

> ⚠️ Это серая зона по ToS 2ГИС, требует Python+Chrome, работает медленнее API
> и может натыкаться на капчу (инструмент ставит сбор на паузу для ручного
> решения — автоматического обхода капчи нет). Рекомендуется как запасной
> вариант, когда нет API-ключа.

### Источник ВКонтакте — официальный VK API

Собирает бизнес-сообщества по нише (`groups.search` + `groups.getById`) с их
публичными контактами (сайт, телефон, город, число подписчиков).

1. Создайте приложение на **https://dev.vk.com/** → раздел «Мои приложения».
2. Получите **сервисный ключ доступа** (service token).
3. Положите в `.env` как `VK_SERVICE_TOKEN`.

Фильтр «без сайта» = у сообщества не указан внешний сайт (поле `site`).

### Источник Telegram — публичные каналы

Собирает публичные бизнес-каналы как лиды. Два режима:
- **По нише** — через TGStat API (ключ `TGSTAT_API_KEY`, https://api.tgstat.ru).
- **По списку** — без ключа: передайте `usernames` (через запятую/ссылками),
  парсятся публичные страницы `t.me/<channel>` (название, описание, подписчики,
  внешний сайт из описания).

> Это сбор **публичных каналов бизнесов** для B2B-аутрича. Накрутки лайков,
> автодействий и выгрузки персональных данных участников здесь нет (см. п. 7).

## 2. Настройка

Добавьте нужные ключи в `.env`:

```env
YANDEX_MAPS_API_KEY=ваш-ключ-яндекса
TWOGIS_API_KEY=ваш-ключ-2gis
VK_SERVICE_TOKEN=ваш-сервисный-ключ-vk
TGSTAT_API_KEY=ваш-ключ-tgstat   # опционально, для поиска каналов по нише

# для 2ГИС-скрапера (опционально)
# PARSER_2GIS_BIN=parser-2gis
# PARSER_2GIS_MAX=500
```

Перезапустите бэкенд:

```bash
npm run dev
```

## 3. Использование через интерфейс

1. Откройте дашборд → в меню слева пункт **«Лиды»**.
2. Выберите **источник**: Яндекс.Карты, 2ГИС, оба сразу или 2ГИС-скрапер.
3. Введите **нишу** (например `кофейня`, `стоматология`, `автосервис`) и **город**.
4. При желании включите галочку **«Только без сайта»**.
5. Нажмите **«Собрать компании»** — результаты появятся в таблице и сохранятся в БД.
   Дубликаты между источниками отсеиваются автоматически.
5. Управляйте статусами лидов (Новый → Связались → Клиент) прямо в таблице.
6. Кнопка **«Экспорт CSV»** выгружает таблицу (открывается в Excel / Google Таблицах).

## 4. Использование через API

### Собрать компании
```bash
curl -X POST http://localhost:3000/api/leads/search \
  -H "Content-Type: application/json" \
  -d '{
    "niche": "кофейня",
    "region": "Москва",
    "noWebsiteOnly": true,
    "limit": 200,
    "save": true,
    "source": "both"
  }'
```

`source` принимает: `yandex` (по умолчанию), `2gis`, `vk`, `telegram`,
`both` (Яндекс + 2ГИС + ВК), `2gis_scraper` (через parser-2gis).

Telegram по списку каналов (без ключа TGStat):

```bash
curl -X POST http://localhost:3000/api/leads/search \
  -H "Content-Type: application/json" \
  -d '{ "source": "telegram", "usernames": "@shop1, t.me/cafe2, studio3" }'
```

Для 2ГИС-скрапера можно передать прямой URL поиска 2ГИС вместо ниши:

```bash
curl -X POST http://localhost:3000/api/leads/search \
  -H "Content-Type: application/json" \
  -d '{ "source": "2gis_scraper", "url": "https://2gis.ru/moscow/search/кофейня" }'
```

Ответ:
```json
{ "success": true, "found": 47, "saved": 47, "bySource": { "yandex": 30, "2gis": 17 }, "leads": [ ... ] }
```

### Список лидов (с фильтрами)
```bash
# Только без сайта
GET /api/leads?hasWebsite=false

# По нише и статусу
GET /api/leads?niche=кофейня&status=new&page=1&limit=50
```

### Статистика
```bash
GET /api/leads/stats
```

### Обновить статус / заметку
```bash
PUT /api/leads/:id
{ "status": "contacted", "notes": "Отправили КП" }
```

### Экспорт в CSV
```bash
GET /api/leads/export/csv?hasWebsite=false
```

## 5. Какие поля собираются

| Поле        | Описание                                  |
|-------------|-------------------------------------------|
| name        | Название компании                         |
| category    | Основная рубрика                          |
| categories  | Все рубрики                               |
| address     | Адрес                                     |
| phone       | Телефон(ы)                                |
| website     | Сайт (пусто = «нет сайта»)                |
| hasWebsite  | Флаг наличия сайта                        |
| latitude/longitude | Координаты                         |
| yandexUrl   | Ссылка на карточку в Яндекс.Картах        |
| hours       | Часы работы                               |
| niche/region| По какому запросу найден                  |
| status      | Статус в воронке (new/contacted/...)      |

## 6. Ограничения и заметки

- Яндекс отдаёт максимум **500 организаций на один поисковый запрос**. Чтобы собрать
  больше по большому городу — дробите по районам (через параметры `ll` + `spn`,
  они поддерживаются в `POST /api/leads/search`).
- Дубликаты (по названию+адресу) автоматически отсеиваются при сохранении.
- Параметр `noWebsiteOnly` фильтрует компании по отсутствию поля «сайт» в ответе API.

---

## 7. Что сознательно НЕ добавлено и почему

Модуль — это **парсеры лидов** (сбор публичных бизнес-контактов). В него
намеренно не включены инструменты накрутки/автоматизации действий:

- **Автолайкеры / авто-просмотры / накрутка** (например, `autotelegram_liker`) —
  это нарушение ToS Telegram/VK, ведёт к бану аккаунтов и портит репутацию
  агентства. Это не лид-ген, а спам-активность.
- **«Deskgram»-инструменты накрутки сторис/упоминаний** — неофициальная
  автоматизация с высоким риском блокировки и сбором персональных данных.
- **Массовая выгрузка участников групп/каналов** для холодных рассылок — это
  обработка персональных данных без согласия (риск по 152-ФЗ) и спам.

Лучшая и легальная стратегия для агентства: собирать **публичные бизнес-аккаунты
и их контакты** (карты, сообщества, каналы) и вести по ним B2B-аутрич с оффером.
