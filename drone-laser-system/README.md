# Selkorin Sky Sentinel

Компактная оптико-электронная установка для **мониторинга ночного неба**,
обнаружения дронов и автоматического наведения лазера.

Система работает в двух режимах:

| Режим | Цель | Действие лазера | Безопасность |
|-------|------|-----------------|--------------|
| `drone` | Дроны / БПЛА в небе | **Подсветка и маркировка** цели маломощным лучом (наблюдение) | Луч, безопасный для глаз, зоны запрета огня |
| `insect` | Комары / насекомые в ближней зоне | **Уничтожение** сфокусированным лучом | Только в огороженной ближней зоне, множественные блокировки |

> ⚠️ **Прочитайте [SAFETY.md](SAFETY.md) до сборки и запуска.** Лазеры опасны
> для зрения, а наведение лучей на воздушные суда и людей запрещено законом
> в большинстве стран. Проект спроектирован так, чтобы физически и программно
> исключить опасные сценарии — не отключайте блокировки.

## Принцип работы

```
┌──────────┐   кадр    ┌───────────┐  цель(px)  ┌──────────┐  угол   ┌──────────┐
│  Камера  │──────────▶│ Детектор  │───────────▶│ Трекер   │────────▶│ Гимбал   │
│ + оптика │           │ (CV)      │            │ (Калман) │  азимут │ (2 оси)  │
└──────────┘           └───────────┘            └──────────┘  угол   └──────────┘
                                                       │ место                │
                                                       ▼ есть                  ▼
                                                 ┌────────────┐          наведение
                                                 │ Безопасность│◀── блокировки, E-STOP
                                                 └────────────┘
                                                       │ разрешено
                                                       ▼
                                                 ┌────────────┐
                                                 │   Лазер     │  подсветка / уничтожение
                                                 └────────────┘
```

1. **Камера** (в паре с ИК-подсветкой или тепловизором) снимает ночное небо.
2. **Детектор** вычитает фон и находит движущиеся объекты, отсеивая звёзды и шум.
3. **Трекер** сопровождает цель фильтром Калмана и предсказывает её положение.
4. Координаты цели в пикселях пересчитываются в **углы азимута/возвышения**.
5. **Гимбал** наводит оптическую ось на цель PID-регулятором.
6. **Менеджер безопасности** проверяет все блокировки перед любым включением лазера.
7. **Лазер** подсвечивает дрон или (в режиме `insect`) поражает насекомое.

Подробности — в [docs/architecture.md](docs/architecture.md).

## Быстрый старт (симуляция, без «железа»)

Весь конвейер можно запустить на обычном ПК — приводы и лазер эмулируются.

```bash
cd drone-laser-system
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# демо в симуляторе: синтетические цели, вывод наведения и решений безопасности
python -m dls --config config/system.yaml --sim --duration 15

# модульные тесты
pytest -q
```

Симулятор генерирует движущиеся цели, прогоняет через них весь конвейер
(детектор → трекер → пересчёт углов → PID гимбала → логика лазера через
блокировки безопасности) и печатает состояние системы каждый кадр.

## Запуск на реальном оборудовании

1. Соберите механику по [docs/mechanical.md](docs/mechanical.md) (модели в `hardware/cad`).
2. Соберите электронику по [docs/electronics.md](docs/electronics.md).
3. Прошейте контроллер привода/лазера (`hardware/firmware/gimbal_controller`).
4. Откалибруйте камеру и оси по [docs/calibration.md](docs/calibration.md).
5. В `config/system.yaml` переключите backend'ы:
   ```yaml
   gimbal: { backend: serial, serial_port: /dev/ttyUSB0 }
   laser:  { backend: serial }
   camera: { device: 0 }
   ```
6. Запустите:
   ```bash
   python -m dls --config config/system.yaml
   ```

Ключ аппаратного взведения (`require_key`) и физическая кнопка E-STOP
обязательны — см. [SAFETY.md](SAFETY.md).

## Рекомендуемая аппаратная платформа

- **Вычислитель:** Raspberry Pi 5 / NVIDIA Jetson Orin Nano (CV в реальном времени).
- **Камера:** монохромная USB/CSI-камера с высокой чувствительностью + ИК-подсветка
  850/940 нм; опционально тепловизор (FLIR Lepton / Boson) для истинно ночного неба.
- **Привод:** 2 шаговых двигателя NEMA 17 с редукторами (азимут/возвышение) или
  сервоприводы с обратной связью; драйверы TMC2209.
- **Контроллер осей:** Arduino/STM32 (детерминированное управление, аппаратные блокировки).
- **Лазер подсветки (дрон):** зелёный 520 нм ≤5 мВт или ИК-осветитель (безопасно для глаз).
- **Лазер поражения (насекомые):** маломощный фокусируемый диод в защищённом корпусе.

Полная спецификация — [docs/bom.csv](docs/bom.csv).
