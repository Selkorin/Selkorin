# Механические чертежи

Модели параметрические, исходники — в [../hardware/cad](../hardware/cad) (OpenSCAD).
Для получения STL: `openscad -o gimbal.stl hardware/cad/gimbal.scad`.

## 1. Общая компоновка (вид сбоку)

```
                    ┌─────────────┐
                    │  Камера +   │   ← оптический блок на площадке возвышения
                    │  ИК/лазер   │
                    └──────┬──────┘
                           │  ось ВОЗВЫШЕНИЯ (tilt), ±0…85°
                    ┌──────┴──────┐
                    │  U-образная │   ← вилка (yoke)
                    │    вилка    │
                    └──────┬──────┘
                           │  ось АЗИМУТА (pan), ±170°
                    ╔══════╧══════╗
                    ║  Поворотная ║   ← опорно-поворотный узел (подшипник)
                    ║   платформа ║
                    ╠═════════════╣
                    ║  Корпус     ║   ← электроника, драйверы, БП
                    ║ электроники ║
                    ╚═════════════╝
                    ▔▔▔▔▔▔▔▔▔▔▔▔▔  ← основание / тренога
```

## 2. Кинематика

Двухосевой поворотный механизм (гимбал) типа «азимут-возвышение» (alt-azimuth):

| Ось | Диапазон | Привод | Редукция | Разрешение* |
|-----|----------|--------|----------|-------------|
| Азимут (pan) | −170°…+170° | NEMA17 + ремень/редуктор | 5:1 | ≈0.036°/микрошаг |
| Возвышение (tilt) | 0°…+85° | NEMA17 + редуктор | 5:1 | ≈0.036°/микрошаг |

\* при 200 шагах/об, 1/16 микрошага и редукции 5:1:
`360 / (200·16·5) ≈ 0.0225°`. С учётом люфта закладываем ~0.05°.

Требуемая точность наведения определяется угловым размером цели и расстоянием.
Для подсветки дрона Ø0.3 м на 200 м угловой размер ≈ 0.086°, значит точность
наведения должна быть заметно лучше — ~0.02–0.05°, что достижимо.

## 3. Ключевые размеры (параметры в `gimbal.scad`)

| Параметр | Значение по умолчанию | Описание |
|----------|-----------------------|----------|
| `base_d` | 160 мм | Диаметр опорной платформы |
| `yoke_h` | 120 мм | Высота вилки |
| `yoke_w` | 90 мм | Ширина между щёками вилки |
| `optics_l` | 140 мм | Длина оптической площадки |
| `bearing_d` | 60 мм | Посадочный диаметр упорного подшипника |
| `motor_flange` | 42.3 мм | Фланец NEMA17 |
| `wall` | 3 мм | Толщина стенок печатных деталей |

## 4. Материалы и изготовление

- Печатные детали: PETG или ASA (стойкость к УФ/погоде), заполнение ≥ 40 %.
- Ответственные узлы (кронштейн лазера, ось): алюминий по возможности.
- Упорный подшипник азимута + радиальные подшипники осей.
- Крепёж M3/M4, резьбовые втулки (heat-set) в печатных деталях.
- Защитный колпак апертуры лазера (шторка) на сервоприводе.

## 5. Юстировка оптической оси

Оптическая ось камеры и ось лазера должны быть **соосны/параллельны** и
откалиброваны на боресайт (см. [calibration.md](calibration.md)). Кронштейн
лазера (`laser_mount.scad`) имеет юстировочные винты по двум осям.

## 6. Погодозащита

- Корпус электроники — IP54+, гермовводы кабелей.
- Бленда/козырёк над оптикой от осадков и засветки.
- Подогрев/обдув стекла против запотевания (опционально).
