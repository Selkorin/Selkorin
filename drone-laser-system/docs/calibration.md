# Калибровка

Наведение точно ровно настолько, насколько точна калибровка. Порядок:

## 1. Калибровка камеры (внутренние параметры)

Определяем фокусные расстояния `fx, fy` (в пикселях) и центр `cx, cy`.

1. Распечатайте шахматную доску (например 9×6, клетка 25 мм).
2. Снимите 15–20 кадров под разными углами.
3. Посчитайте параметры (OpenCV):

```python
import cv2, numpy as np, glob
pattern = (9, 6)
objp = np.zeros((pattern[0]*pattern[1], 3), np.float32)
objp[:, :2] = np.mgrid[0:pattern[0], 0:pattern[1]].T.reshape(-1, 2)
objpoints, imgpoints = [], []
for f in glob.glob("calib/*.png"):
    img = cv2.imread(f); gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
    ok, corners = cv2.findChessboardCorners(gray, pattern)
    if ok:
        objpoints.append(objp); imgpoints.append(corners)
ret, K, dist, _, _ = cv2.calibrateCamera(objpoints, imgpoints, gray.shape[::-1], None, None)
print("fx,fy,cx,cy =", K[0,0], K[1,1], K[0,2], K[1,2])
```

4. Впишите `fx, fy, cx, cy` в `config/system.yaml → camera`.

## 2. Хоуминг осей

Команда `HOME` выводит оси на концевые выключатели и обнуляет отсчёт.
Проверьте направление вращения и знаки в конфиге (`pan`/`tilt`).

## 3. Боресайт (совмещение оптической оси и лазера)

Цель: точка на изображении `(cx, cy)` должна соответствовать точке, куда
светит лазер, когда система наведена.

1. Установите мишень на известном расстоянии (напр. 25 м), в очках, малой мощностью.
2. Наведите систему так, чтобы лазерное пятно совпало с центром кадра.
3. Юстировочными винтами кронштейна лазера сведите пятно в перекрестие `(cx, cy)`.
4. Проверьте на 2–3 расстояниях (параллакс из-за смещения лазера от оптоси).
5. Если есть остаточное смещение, задайте поправку `boresight_offset_deg`
   в конфиге (см. `coordinates.py`).

## 4. Проверка точности наведения

- Подайте известные углы, измерьте фактическое положение (уровень/теодолит/лазерный
  дальномер) — оцените ошибку и повторяемость.
- Настройте PID (`pid_pan`, `pid_tilt`): увеличивайте `kp` до лёгкого перерегулирования,
  добавьте `kd` для гашения колебаний, минимальный `ki` от статической ошибки.

## 5. Проверка масштаба (пиксель → угол)

Наведите на объект известного углового размера; убедитесь, что смещение цели
на N пикселей даёт корректную угловую поправку. При ошибке — уточните `fx, fy`.
