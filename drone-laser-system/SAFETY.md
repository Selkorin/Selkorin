# Безопасность, блокировки и юридические аспекты

> Этот документ обязателен к прочтению. Проект целенаправленно спроектирован так,
> чтобы исключить опасные и незаконные сценарии применения. Программные и
> аппаратные блокировки — часть конструкции, а не опция.

## 1. Классы лазеров и опасность для зрения

| Класс | Ориентир по мощности (видимый) | Опасность |
|-------|-------------------------------|-----------|
| 1 / 1M | — | Безопасен при нормальном использовании |
| 2 / 2M | ≤ 1 мВт | Защита — моргательный рефлекс; не смотреть в луч |
| 3R | 1–5 мВт | Опасен при прямом попадании в глаз |
| 3B | 5–500 мВт | Опасен, в т.ч. диффузное отражение вблизи |
| 4 | > 500 мВт | Опасен для глаз и кожи, пожароопасен |

- **Режим подсветки дрона** использует источник **класса ≤ 3R** (видимый ≤ 5 мВт)
  или ИК-осветитель в пределах гигиенических норм — задача только *обозначить* цель,
  а не повредить её.
- **Режим уничтожения насекомых** использует более мощный сфокусированный луч
  (фактически класс 3B/4). Поэтому он разрешён **только** в ограниченной ближней
  зоне внутри защитного ограждения и при выполнении всех блокировок (см. §4).

Всегда используйте защитные очки, рассчитанные на длину волны конкретного лазера.

## 2. Юридические ограничения (критично)

- **Наведение лазера на воздушные суда запрещено** законом практически во всех
  странах (ослепление пилотов). Даже маломощная подсветка пилотируемого борта —
  уголовное правонарушение.
- Поэтому в режиме `drone` система **по умолчанию не стреляет ниже линии горизонта**,
  соблюдает **зоны запрета огня** (маршруты, аэродромы, жилая застройка) и
  ограничивает подсветку неопознанных объектов, которые могут оказаться самолётом.
- **«Сбивать»/выводить из строя чужие дроны лазером в общем случае незаконно.**
  Данный проект в режиме `drone` **не поражает** дрон — он только обнаруживает,
  сопровождает и маркирует его для наблюдения. Не модифицируйте систему для
  причинения вреда воздушным судам.
- Видеонаблюдение неба может попадать под законодательство о ПДн/приватности —
  ответственность на эксплуатанте.
- Применение по любым целям, кроме указанных (насекомые в защищённой зоне),
  требует отдельной юридической проработки.

## 3. Обязательные аппаратные средства безопасности

1. **Кнопка аварийного останова (E-STOP)** — нормально-замкнутая, физически
   разрывающая питание лазера (не через ПО). Легко доступна.
2. **Ключ взведения (arming key)** — лазер невозможно включить без ключа.
3. **Индикатор излучения** — светодиод/сигнал при активном лазере (требование норм).
4. **Концевые выключатели** осей — механическое ограничение хода.
5. **Оптический затвор/защитная шторка** — перекрывает апертуру в покое.
6. **Термодатчик лазера** — отключение при перегреве.
7. **Защитное ограждение / бокс** для режима уничтожения насекомых.

## 4. Программные блокировки (реализованы в `dls/safety`)

Любой запрос на включение лазера проходит через `SafetyManager.evaluate()`.
Огонь разрешается, только если **одновременно** выполнены все условия:

- Система **взведена** ключом (`require_key`).
- E-STOP **не нажат**.
- **Watchdog** свеж (главный цикл жив, канал управления не завис).
- Цель **вне зон запрета огня** (по умолчанию — ниже горизонта огонь запрещён).
- Соблюдены пределы по **времени непрерывного излучения** и **тепловому режиму**.
- Для режима `insect` дополнительно:
  - цель в пределах **max_range** (ближняя зона),
  - **нет присутствия человека/крупного объекта** в секторе (интерлок),
  - уровень освещённости в норме (исключает работу вне защищённой зоны),
  - подтверждённый трек с классификацией «насекомое».

При нарушении любого условия лазер немедленно гасится, система переходит
в состояние `SAFE`, событие логируется.

## 5. Конечный автомат безопасности

```
   ┌──────┐  ключ + самопроверка   ┌───────┐  цель + все блокировки OK   ┌────────┐
   │ SAFE │───────────────────────▶│ ARMED │────────────────────────────▶│ FIRING │
   └──────┘                        └───────┘                             └────────┘
      ▲   ▲                            │  ▲                                   │
      │   └──── E-STOP / отказ / ──────┘  └───────── цель ушла / таймаут ─────┘
      │         watchdog / нарушение
      └────────────────────────────── любое нарушение → SAFE ─────────────────
```

Переход в `FIRING` невозможен в обход `ARMED`. Любая ошибка отбрасывает
систему в `SAFE`. По умолчанию система стартует в `SAFE`.

## 6. Регламент испытаний

1. Первый запуск — **только в симуляции** (`--sim`), без питания лазера.
2. Проверка механики и наведения — **с заглушкой вместо лазера**.
3. Проверка E-STOP и всех блокировок — **до** подачи питания на лазер.
4. Юстировка и работа лазера — в защищённом помещении, в очках, при
   ограниченной мощности, с оформленным допуском.

Никогда не эксплуатируйте систему без работающего E-STOP и индикатора излучения.
