# site-audit — аудит публичного сайта

Неинтрузивный чёрный-ящик аудит: инструмент открывает страницы обычными
GET-запросами (как поисковый робот) на трёх вьюпортах (mobile / tablet /
desktop) и собирает недостатки по шести направлениям:

- **Производительность** — LCP, CLS, TTFB, вес страницы, число запросов, тяжёлые
  и неоптимизированные картинки, размер DOM, длинные JS-задачи.
- **SEO** — title/description, h1, canonical, Open Graph, микроразметка JSON-LD,
  robots.txt / sitemap.xml, soft-404, дубли www / без-www.
- **Доступность (a11y)** — контраст текста (WCAG), alt у картинок, `<label>` у
  полей, доступные имена кнопок/ссылок, `<html lang>`, иерархия заголовков.
- **Мобильная вёрстка** — горизонтальный скролл, мелкие зоны нажатия, мелкий шрифт.
- **Безопасность (пассивно)** — HTTPS-редирект, HSTS, CSP, X-Frame-Options,
  X-Content-Type-Options, сжатие, срок и валидность TLS-сертификата, утечка
  версий ПО в заголовках.
- **Юридическое / доверие (РФ)** — политика обработки перс. данных (152-ФЗ),
  оферта/условия, реквизиты продавца, чекбокс согласия в формах.

Инструмент **не делает** активного пентеста: без перебора путей, без инъекционных
пейлоадов, без брутфорса и без нагрузочного тестирования.

## Запуск

Нужна машина с выходом в интернет (в облачной сессии Claude Code внешний
egress закрыт политикой — там скрипт не отработает).

```bash
cd tools/site-audit
npm install
npx playwright install chromium   # один раз

node audit.mjs https://puffinpizza.ru/ --paths=/,/catalog/picca,/promo
```

Флаги:

| Флаг | По умолчанию | Назначение |
|---|---|---|
| `--paths=/a,/b` | `/` | какие пути проверять |
| `--out=DIR` | `./audit-report` | куда сложить отчёт |
| `--timeout=MS` | `45000` | таймаут навигации |

## Результат

```
audit-report/
  report.md      ← читаемый отчёт с находками по приоритетам
  report.json    ← все метрики и находки (для дальнейшей обработки)
  screenshots/   ← полностраничные скриншоты по каждому вьюпорту
```

Пришлите мне `report.md` (или `report.json`) и скриншоты — я разберу результат,
приоритизирую недостатки и предложу, что чинить в первую очередь.
